AI Cost Board

Shows, live on a projector, how much money an OpenRouter API key has spent while the class uses it.

    For instructors: how this works

    A management key (create one at openrouter.ai/settings/management-keys) can list, create and delete every API key in the workspace, so it is never shown on screen and is kept only in this browser tab unless you tick "Remember". This page reads GET https://openrouter.ai/api/v1/keys/{hash} on a timer and shows the key's usage (dollars spent, all time) and limit_remaining (dollars left, if the key has a credit limit). It never changes a key. "This class" counts from the moment the board opened. Each jump in spending is usually one AI request, but if several requests land between checks they show as one jump. OpenRouter can take a few seconds to record a request's cost.

    Keyboard on the board: F full screen, T light/dark, Esc or K back to key list.
