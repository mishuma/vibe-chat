Settings

Requests to the model stop when this session has spent this much, and the colored bar at the top is full. Raise the limit at any time to continue; the conversation is kept. Leave empty for no limit of your own. OpenRouter enforces the key's own limits separately and reports them in the chat. The limit is saved in this browser; the amount spent restarts when the page is reloaded.

How the assistant writes code

Code language, extra instructions and the comments setting are added to the system prompt, so they are sent (and paid for) with every message and apply from the next message. With comments on, the code explains itself in the style of its language (// for TypeScript and JavaScript, # and docstrings for Python); turn it off for shorter code. Code colors only change how the code window looks, not what is copied or saved. All of these are saved in this browser. Your extra instructions take priority over the default style rules.
