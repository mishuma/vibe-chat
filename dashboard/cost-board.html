AI Cost Board

    For instructors: how this works

    A management key (create one at openrouter.ai/settings/management-keys) can list, create and delete every API key in the workspace, so it is never shown on screen and is kept only in this browser tab unless you tick "Remember". This page reads GET https://openrouter.ai/api/v1/keys/{hash} on a timer and shows the key's usage (dollars spent, all time) and limit_remaining (dollars left, if the key has a credit limit). It never changes a key. Keys from every workspace in the account are listed (via GET /api/v1/workspaces), grouped by workspace when there is more than one. "This class" counts from the moment the board opened. Each jump in spending is usually one AI request, but if several requests land between checks they show as one jump. OpenRouter can take a few seconds to record a request's cost.

    OpenRouter bills in US dollars. In shekels, the board converts with the rate shown at the bottom of the screen: the European Central Bank rate from frankfurter.dev, fetched when you choose shekels or click "Get today's rate", or a rate you type in yourself. The Hebrew interface turns the layout right-to-left; these notes stay in English.

    Two ways to show keys: click one key to show only that key, or use "Cycle through every key in a workspace" to show each enabled key in turn for the chosen number of seconds (1 to 60). "Entire Class" adds up every enabled key in the workspace: it can be part of the cycle (shown first) or shown on its own with "Show Entire Class only". It shows money left only when every key has a spending limit; otherwise it shows the total spent. While cycling, one request per check reads the whole workspace, so every key's "this class" total stays correct even while it is off screen.

    Keyboard on the board: F full screen, Space pause/resume cycling, ←/→ previous/next key while cycling, T light/dark, L switches between English with dollars and Hebrew with shekels (the class count keeps running), Esc or K back to key list. The keys work with a Hebrew keyboard layout too.
